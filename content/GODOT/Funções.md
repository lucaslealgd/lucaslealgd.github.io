Para criar uma função vamos começar fazendo:
```gdscript
func name():
	# instrucao
```

- Regras de nomenclatura:
	- Não conter espaços (o computador vai entender o espaço como uma separação entre as palavras chave e identificadores)
		- **Podemos usar underline (`_`) para separar**
	- Por padrão usamos palavras em letra minúscula separadas por `_`, ex: "primeira_funcao_criada"
		- Em outras linguagens o padrão pode ser diferente (como primeiraFuncaoCriada)
	- Precisa começar com uma letra ou `_`
